Cinema Dusk theme for EVA Launcher
===================================
Files
  config.json            the Cinema Dusk theme (slate-teal vignette & glass dock band)
  config.dock-band.json  alternative dock band config
  wallpaper.jpg          default wallpaper (slate-teal cinema vignette, 1920x1080)
  wallpapers/            dusk, ember: shown in Launcher settings > Wallpaper & Themes

Install with adb:
  Windows PowerShell:  .\install-theme.ps1
  macOS / Linux:       ./install-theme.sh
